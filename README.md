# HA-Migrate

HA-Migrate is a simple and powerful migration tool for Home Assistant running in Docker.

## Features

- Install Home Assistant dependencies
- System health check (Doctor)
- Backup Home Assistant configuration
- Verify backup integrity
- Restore from backup (Coming Soon)
- Update tool (Coming Soon)

## Requirements

- Ubuntu 24.04+
- Docker
- Git

## Installation

```bash
git clone https://github.com/nazmul497-cmd/ha-migrate.git
cd ha-migrate
chmod +x *.sh ha-migrate
./ha-migrate
```
